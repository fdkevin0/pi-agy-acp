# Security policy

Security fixes target the latest published version. Upgrade before checking
whether an issue still reproduces.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/fdkevin0/pi-agy-acp/security/advisories/new).
Do not disclose vulnerabilities in public issues or pull requests.

Include affected versions, reproduction steps, expected and actual behavior,
and the potential impact. Remove credentials, account identifiers, and private
conversation content from any logs or examples. Never send live access tokens.

This project is maintained by one person; response times are not guaranteed.
